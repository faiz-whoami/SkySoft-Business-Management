# business_managment_system

ASP.NET MVC 5 (.NET Framework 4.8) web application. The on-screen product name is **SkySoft Business Management**.

Open this file in Visual Studio (same name as before):

`business_managment_system.slnx`

## Run

1. Open `business_managment_system.slnx` in Visual Studio.
2. If Visual Studio asks to restore NuGet packages, choose Restore.
3. Press **F5**.

You should see the dashboard shell and the left menu.

The old Razor Pages / .NET 10 files (`Program.cs`, `Pages/`, `appsettings.json`) are gone. The project now uses `Web.config`, MVC controllers, and .NET Framework 4.8.

Login and database come in the next modules.
